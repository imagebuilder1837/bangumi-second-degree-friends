## 安装

1. 可以通过[这个链接](https://bgm.tv/dev/app/7363)在 Bangumi 组件页面启用。
2. 也可以通过[这个链接](https://raw.githubusercontent.com/imagebuilder1837/bangumi-second-degree-friends/refs/heads/main/src/index.user.js)安装到常见的脚本管理器，需要浏览器装有 [Tampermonkey](https://tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/) 插件。
