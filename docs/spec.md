# 二度好友发现：行为规格

领域术语见 [GLOSSARY.md](../GLOSSARY.md)。本文规定关系发现、缓存与界面行为；原站结构和浏览器依赖事实见 [外部调查](external/bangumi.md)。

## 关系发现

- 第一跳方向决定中间用户集合，第二跳方向决定从中间用户读取哪种关系。所有模式均排除主页用户；第二跳为好友时排除主页用户的好友，第二跳为反向好友时排除主页用户的反向好友。因此混合模式中的中间用户仍可能成为候选。
- 同一关系列表按用户标识去重。每位候选的关联人数按不同中间用户计算，重复条目和重试不增加人数；读取失败的中间用户不贡献候选或人数，未完成结果只代表已成功观察到的关联。
- 主动寻找重新读取全部所需关系，不用旧缓存补齐读取失败。主页的第一跳或排除关系读取失败时，不开始扫描中间用户；单个中间用户最终读取失败后继续处理其他用户，但结果标为未完成。

## 读取与取消

- 仅在受支持域名的 HTTPS 用户主页挂载入口；主页身份和关系链接须匹配当前用户标识。读取使用同源凭据，关系页面的身份、链接与列表结构须通过校验。响应最终 URL 与请求 URL 不一致、身份不符或无法识别的列表均属于失败，不能当成空关系。此检查不代表浏览器不会跟随重定向。
- 瞬时网络或正文读取错误、超时、HTTP 408 与 5xx 有限重试；其他客户端错误、跳转与解析失败不重试。503 的有效 `Retry-After` 约束重试等待下限。
- 停止或收到 429 时，取消当前扫描的在途请求和重试等待，不再调度后续关系读取；保留已展示的部分结果，晚到响应不能继续更新结果。429 使用有效的 `Retry-After` 确定冷却截止时间，缺失或无效时采用默认冷却。
- 扫描、停止和冷却状态仅属于当前页面实例，不跨标签页共享；同一页面不并行运行多个扫描，旧缓存读取也不能覆盖较新的模式或扫描结果。

## 缓存

- 缓存保存关系快照，而非某模式的最终排名；查询时按所选模式重建结果。主页的第一跳、排除方向，以及所有第一跳中间用户的第二跳快照必须齐全，才展示完整缓存。相同方向共用快照；缺失代表未知，显式空集合可以完整。
- 快照不按年龄过期，可以跨扫描和模式组合不同时间取得的观察。“完整”仅指所需快照齐全，不保证实时性或同一时刻的关系图。
- 只有完整扫描才尝试整体提交；失败、停止或限流不保存本次暂存结果。保存失败保留旧缓存和已完成的实时结果，扫描完整与保存成功分别表达。
- 同源并发写入在事务内读取最新缓存后合并，保留无关用户及方向；按观察时间保留较新快照，相同时间允许后提交者替换。写入失败或事务完成前取消时整体回滚。其他已打开页面的结果不因缓存写入而自动刷新。

## 信息层级

- 顶部依次为“开始寻找”、四种关系模式下拉框、关闭按钮 ×，不重复展示大标题或“模式”标签。
- 操作区与状态区固定，只有候选用户列表滚动。窄屏允许关系说明换行，不出现弹窗内横向滚动。
- 视觉沿用 Bangumi 的紧凑排版、链接色与明暗主题；“开始寻找”使用粉底白字，不取代排名配色。控件 hover 不添加粉色边框，键盘焦点提示保持可见。
- 候选摘要行依次为框内序号、头像与昵称、关系说明、展开按钮。序号放大，以摘要行垂直居中；展开头像区不改变序号的对齐基准。
- 按关联的中间用户人数降序排列，同分按用户标识字符串升序。扫描期间序号为临时排名；只有完整结果（含完整缓存结果）的前三名使用金银铜底色。

## 关系说明

A 代表主页用户，实际显示其昵称；TA 指该行候选用户；N 为实际关联的不同中间用户人数。

| 模式 | 文案 |
| --- | --- |
| 好友的好友 | A 的 N 位好友加了 TA |
| 好友的反向好友 | TA 加了 A 的 N 位好友 |
| 反向好友的好友 | A 的 N 位反向好友加了 TA |
| 反向好友的反向好友 | TA 加了 A 的 N 位反向好友 |

不使用“贡献者”作为界面称呼。展开区仅展示被计入人数的中间用户头像，悬停可查看昵称；不重复添加解释性占位文案。

## 展开与浏览

- 默认全部折叠，允许多行同时展开。独立的“展开 / 收起”按钮附方向箭头；用户头像和昵称链接不触发展开。
- 用户链接在新标签页打开。展开和加载更多仅浏览已有结果，不发起关系请求。
- 候选每批展示 50 条，中间用户头像每批展示 40 个，通过“显示更多”继续加载。
- 实时重排保留每个候选的展开状态及已加载批次；新扫描或切换模式重置这些状态。

## 状态与进度

- 打开时读取缓存，不自动扫描；缓存摘要仅显示“已载入缓存 · N 位候选用户”。关系快照的最早至最晚获取时间采用易读的本地时间，置于默认折叠的“缓存详情”。
- 扫描总数未知时显示“正在获取主页关系”，进度条不显示虚构百分比；总数确定后显示“扫描进度：X/Y”及进度条。X 为已处理的中间用户数，包含成功和失败，并同时说明两者人数。
- 完成后显示候选人数；完整扫描无候选时显示明确的空结果，而不是再次开始的提示。
- 处理进度达到总数不代表结果完整。失败、停止、限流及缓存保存失败必须直接显示，不隐藏在详情中；失败或停止的结果标明未完成。
- 寻找期间主按钮切换为“停止寻找”，模式不可切换。限流冷却结束后须手动重新开始。
- 关闭或 Escape 仅隐藏弹窗，不停止扫描；再次打开保留当前模式、结果与进度。离开页面终止未完成请求。
